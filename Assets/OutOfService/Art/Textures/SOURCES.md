# Environment textures

These eight 2K texture files were downloaded from Poly Haven on 2026-11-08. The assets are CC0 and can be used in the Unity game without attribution; links are kept here for provenance.

- https://polyhaven.com/a/interior_tiles — Diffuse and DirectX normal
- https://polyhaven.com/a/worn_concrete_floor — Diffuse and DirectX normal
- https://polyhaven.com/a/painted_plaster_wall — Diffuse and DirectX normal
- https://polyhaven.com/a/metal_plate_02 — Diffuse and DirectX normal

Source files were checked against the MD5 values returned by `https://api.polyhaven.com/files/{asset_id}` at download time.

`supermarket_gray_tile_v2.png` was generated for this project on 2026-11-09 with OpenAI image generation. It depicts a square grey porcelain supermarket tile grid with subtle scuffs and no baked lighting.

The generic Korean package fronts in `../Packs/` are generated locally by `Tools/GenerateMarketPacks.ps1`; they are mock retail artwork, not photographs of real products.

2026-11-18 surface and lighting revision. PorcelainGroutNormal, PorcelainWearGloss and BrushedSteelGloss in Generated are authored procedurally by Editor/MarketSurfaceFinishV7.cs. The grout follows the existing 600 mm tile grid. ShopReflection0–4 are 128 px cubemaps baked from this project's closed-door scene. They contain project geometry and artwork. No new external material was imported for these additions. Lighting placement and finish values are game art decisions informed by the three amusement-park reference images supplied by the user on 2026-11-18.

Store signs regenerated by Tools/GenerateMarketSigns.ps1 use the original fictional store name Homeway. Printed signs receive local lighting with limited emission.
