# 토끼 괴물 + 짝꿍 + 거북이 (Bunny Monster, Twin & Turtle) 유니티 패키지 v4

괴물 세 마리가 들어 있어요. 토끼와 짝꿍은 거울에 비친 것처럼 좌우가 반대인 쌍둥이이고, 거북이는 같은 뼈대와 같은 AI를 쓰는 새 인형탈 괴물이에요.

| | 토끼 (BunnyMonster) | 짝꿍 (BunnyTwin) |
|---|---|---|
| 털 | 흰색, 분홍 배 | 검은색, 잿빛 배 |
| 표정 | 입이 찢어지게 웃는 얼굴 | 입꼬리가 축 처진 우는 얼굴, 눈에서 피눈물 |
| 접힌 귀 | 오른쪽 | 왼쪽 |
| 뿌연 눈알 / 빈 눈구멍 | 오른쪽 / 왼쪽 | 왼쪽 / 오른쪽 |
| 발톱 | 검은색 | 흰색 |
| 애니메이션 | 기본 | 좌우 반전 (왼다리를 끌고, 고개도 반대로 꺾어요) |

나란히 세우면 접힌 귀가 둘 다 바깥쪽에 오고, 같은 동작을 시키면 거울처럼 대칭으로 움직여요.

### 짝꿍 디테일 (v3.1)
- 팔, 옆구리, 다리 바깥쪽과 목둘레에 실로 꿰맨 봉제선이 있고, 몸 군데군데 찢어진 구멍으로 솜이 삐져나와 있어요.
- 촉수 8개는 상처에서 자라나 중력에 따라 아래로 늘어져요. 촉수마다 뼈가 3개씩 있어서, 몸이 움직이면 살짝 늦게 따라오고 조금씩 흔들려요. 이 움직임은 5개 클립에 미리 구워 넣어서 따로 설정할 게 없어요.
- 마스코트 머리는 통째로 단단하게 움직이고, 목과 어깨 관절은 짧고 고르게 접히도록 스키닝을 새로 했어요. 고개를 젖혀도 얼굴과 입이 늘어나지 않고, 팔을 들어도 가슴 쪽 주름이 딸려 올라가지 않아요.
- 뼈는 몸통 29개에 촉수용 24개가 더해진 53개예요. Generic 리그라서 그대로 동작해요.

### 거북이 인형탈 괴물 (TurtleMonster, v4)
- 놀이공원 마스코트 거북이 인형탈이 괴물이 된 모습이에요. 쫓아올 때 무섭게 보이도록 얼굴을 하이폴리로 깎았어요.
  - 눈: 크고 반들반들한 검은 눈알을 무거운 눈썹뼈와 안쪽으로 비스듬히 덮는 윗눈꺼풀이 누르고 있어서, 정면에서 보면 노려보는 눈매예요. 좌우 눈 크기가 달라요. 눈두덩은 퀭하게 꺼져 있고 눈가는 충혈돼 있어요.
  - 입: 볼까지 찢어진 비대칭 웃음이에요. 입술이 말려 올라가 붉은 잇몸이 드러나고, 길이가 제각각인 삐뚤어진 이빨(송곳니 자리는 더 길고, 부러진 이빨도 있어요) 뒤에 상어처럼 작은 이빨이 한 줄 더 있어요. 안쪽에는 부은 혀가 있고, 이빨 사이로 핏빛 침이 늘어져 있어요.
  - 주름과 피부: 콧등 으르렁 주름, 미간 주름, 이마 주름, 팽팽하게 당겨진 입술 주름, 찢어진 입꼬리의 깊은 주름, 눈 밑 주름, 거북이 비늘 균열과 사마귀 돌기가 있어요. 이마는 찢어져서 살과 촉수가 비집고 나오고 피가 얼굴로 흘러내려요. 왼쪽 볼에는 입꼬리에서 이어지는 꿰맨 흉터가 있어요.
- 배딱지(복갑)는 인갑 홈이 파인 더러운 황갈색 판이고, 세 군데가 갈라져서 피에 젖은 살과 검붉은 촉수가 터져 나와 있어요. 등딱지는 인갑 무늬와 테두리 링이 있는 단단한 껍질이고, 왼쪽 어깨 뒤쪽 균열에서 촉수가 위로 솟아 있어요.
- 병든 회녹색 인형탈은 관절마다 천 주름이 잡혀 있고, 흙때와 핏자국이 묻어 있어요. 손목에는 청록색 커프, 손에는 길고 굽은 검은 손톱 4개, 발에는 굵은 베이지 발톱 3개가 있어요.
- 토끼와 같은 5개 클립을 그대로 쓰지만, 거북이는 등을 살짝 굽히고 고개를 숙인 채 눈썹 아래로 노려보는 자세로 움직여요(덮치는 Attack만 고개를 들어 상대를 봐요). 머리가 커서 어깨 위에 바로 얹혀 있기 때문에, 고개를 끄덕이거나 갸웃하는 각도는 절반으로 줄였어요(좌우로 돌리는 각도는 그대로예요).
- 뼈대를 거북이 몸에 맞게 옮겼어요(방향은 그대로라 동작 의미가 같아요). 귀 뼈는 뺐어요. 머리는 통째로 단단하게 움직이고, 등딱지와 배딱지는 팔다리에 끌려가지 않는 단단한 갑옷처럼 척추를 따라가요. 길이 10cm 이상인 촉수 19개에 뼈가 3개씩 있어서 늦게 따라오며 흔들려요.
- 뼈는 몸통 23개에 촉수용 57개가 더해진 80개예요. 키는 약 1.9m예요.

## 들어 있는 파일
- `Model/bunny_monster.fbx` : 토끼. 리그(뼈 29개), 애니메이션 5개, 메시 2개(LOD)가 한 파일에 들어 있어요.
- `Model/bunny_twin.fbx` : 짝꿍. 구성은 토끼와 같아요(뼈 이름도 같고, 애니메이션 이름도 같아요).
  - `Bunny_Mesh_LOD0` : 하이폴리, 삼각형 약 30만 개. 가까이서 보이는 모델이에요. 눈구멍, 코, 입, 주름, 봉제선, 털 뭉침을 형태로 깎았어요.
  - `Bunny_Mesh_LOD1` : 로우폴리, 삼각형 약 1.7만 개. 멀리서 보이는 모델이에요. 하이폴리 디테일을 노멀맵으로 구워 넣어서 실루엣 말고는 거의 같아 보여요.
- `Textures/bunny_albedo.png` : 색상 텍스처 (2048×2048). 두 LOD가 같이 써요.
- `Textures/bunny_mask.png` : 마스크맵 (R 금속성 0, G 앰비언트 오클루전, A 매끄러움). 두 LOD가 같이 써요. 털과 얼굴은 거의 무광이고, 피 묻은 살·혀·입안만 살짝 젖은 느낌이에요.
- `Textures/bunny_hp_normal.png` : LOD0용 노멀맵 (하이폴리에서 줄이고 남은 아주 잔 디테일)
- `Textures/bunny_normal.png` : LOD1용 노멀맵 (하이폴리 디테일 전체)
- `Textures/twin_*.png` : 짝꿍용 텍스처 4장 (구성은 토끼와 같아요)
- `Model/turtle_monster.fbx` : 거북이. `Turtle_Mesh_LOD0`(삼각형 약 30만 개) / `Turtle_Mesh_LOD1`(약 2만 개), 리그(뼈 80개), 애니메이션 5개
- `Textures/turtle_*.png` : 거북이용 텍스처 4장 (구성은 토끼와 같아요). 인형탈 천은 무광, 등딱지·배딱지는 반무광, 피와 촉수는 젖은 광택, 눈은 반들반들해요.
- `Scripts/BunnyMonster.cs` : 몬스터 AI(배회하다 플레이어를 발견하면 비명, 추격, 공격)와 키보드 테스트 모드
- `Scripts/BunnyInput.cs` : 구 Input Manager와 새 Input System을 둘 다 지원해요
- `Scripts/BunnyDemoPlayer.cs` : 데모 씬에서 쓰는 플레이어(캡슐)
- `Editor/BunnyMonsterSetup.cs` : 메뉴 한 번으로 세팅하는 스크립트

## 설치 (Unity 2021.3 LTS 이상 / Built-in, URP, HDRP 모두 지원)
1. 압축을 풀고 `BunnyMonster` 폴더를 유니티 Project 창의 `Assets` 안으로 끌어다 놓아요.
   - 예전 버전을 넣어 둔 적이 있으면 그 폴더를 먼저 지우고 넣어 주세요.
2. 컴파일이 끝나면 상단 메뉴 **Tools > Bunny Monster > 1. Setup**을 실행해요.
   - FBX 임포트 설정(Generic 리그, 클립 이름 정리, Idle·Walk·Run 루프)
   - 세 마리 모두 한 번에 세팅해요
   - 지금 쓰는 렌더 파이프라인에 맞는 머티리얼 생성(괴물마다 `_LOD0_Mat`, `_LOD1_Mat` 2개씩), 노멀맵·마스크맵 자동 연결
   - 무광 설정: 환경 반사를 꺼서 얼굴과 눈이 번들거리지 않게 해요
   - LOD Group 설정: 화면 높이의 30% 이상 크게 보이면 하이폴리(LOD0), 그보다 작으면 로우폴리(LOD1)로 자동 전환돼요
   - `BunnyMonster.prefab` / `BunnyTwin.prefab` / `TurtleMonster.prefab`과 각각의 Animator Controller 생성
3. **Tools > Bunny Monster > 2. Create Demo Scene**을 실행하고 Play를 눌러요.
   - WASD나 방향키로 캡슐(플레이어)을 움직이고, Shift로 달려요.
   - 토끼, 짝꿍, 거북이가 나란히 서 있다가, 플레이어를 보면 비명을 지르고 쫓아와요. 가까워지면 공격하고, 잡히면 Console에 `Caught` 로그가 떠요.
   - 선반 뒤에 숨으면 시야가 막혀서 발견되지 않아요.

## 내 게임에 넣기
- `BunnyMonster.prefab`, `BunnyTwin.prefab`, `TurtleMonster.prefab` 중 하나를 씬에 놓고 Inspector의 **Target**에 플레이어를 넣으면 돼요. 셋 다 같은 AI 스크립트와 같은 Animator 파라미터를 써요.
- **onSpotted**(발견하는 순간)와 **onAttackHit**(공격이 닿는 순간, 0.5초) 이벤트에 점프스케어, 사운드, 게임오버를 연결하면 돼요.
- Target을 비워 두면 키보드 테스트 모드가 돼요. WASD 이동, Shift 달리기, Space 공격, R 비명이에요.
- 이동 속도는 걷기 **0.9 m/s**, 달리기 **2.6 m/s**예요. 애니메이션 발걸음에 맞춘 값이라 바꾸면 발이 미끄러져 보일 수 있어요. 바꿀 때는 Animator > Locomotion 블렌드 트리의 Walk·Run 값도 같이 바꿔 주세요.
- 다른 스크립트에서 직접 제어할 때 쓰는 Animator 파라미터: `Speed`(float, m/s), `Attack`(trigger), `Scream`(trigger)
- 실제 맵에서는 `BunnyMonster`의 이동 부분을 NavMeshAgent로 바꾸면 벽을 돌아서 쫓아와요(지금은 직선으로 다가와요).

## 성능 팁 (하이폴리)
- 하이폴리(LOD0)는 가까이 있을 때만 그려지고, 숨어 있는 LOD는 스키닝도 하지 않게 해 뒀어요.
- 토끼를 한 화면에 여러 마리 띄우거나 모바일에서 쓸 때는 프리팹의 **LOD Group**에서 LOD0 구간을 줄이거나(예: 50%), LOD0를 지우고 LOD1만 쓰면 돼요.
- 컷신이나 점프스케어처럼 얼굴을 크게 보여 주는 장면에서는 LOD Group의 **Force LOD**(코드: `GetComponentInChildren<LODGroup>().ForceLOD(0)`)로 하이폴리를 고정하면 좋아요.

## 애니메이션 클립 (30fps, 제자리 동작)
| 클립 | 길이 | 루프 | 내용 |
|---|---|---|---|
| Idle | 3.0초 | O | 구부정하게 숨 쉬다가 고개를 홱 꺾어요 |
| Walk | 1.33초 | O | 오른쪽 다리를 끌며 걸어요 |
| Run | 0.8초 | O | 팔을 앞으로 뻗고 달려들어요 |
| Attack | 1.4초 | X | 팔을 들어 올렸다가 덮쳐요(0.5초에 타격) |
| Scream | 2.0초 | X | 고개를 젖히고 팔을 벌린 채 몸을 떨어요 |

## 문제 해결
- 모델이 분홍색이에요: 렌더 파이프라인을 바꿨다면 **1. Setup**을 다시 실행해 주세요.
- 아직 번들거려요: 씬의 Reflection Probe나 Skybox가 아주 밝으면 그럴 수 있어요. 머티리얼의 Smoothness 배율(URP `Smoothness`, Built-in `Gloss Map Scale`)을 0.5로 낮춰 보세요.
- 가까이 갔는데 로우폴리로 보여요: 프리팹의 LOD Group에서 LOD0 경계(기본 30%)를 낮춰 주세요.
- 크기가 이상해요: Setup이 키를 약 2.1m로 자동 보정해요.
- 새 Input System만 쓰는 프로젝트에서도 그대로 동작해요.
- Humanoid로 쓰고 싶어요: 뼈 이름이 Mixamo 방식이라 Rig를 Humanoid로 바꾸면 자동으로 매핑돼요. 다만 귀와 꼬리는 Humanoid 리타깃 대상이 아니라서 마스크 설정이 따로 필요해요. 그래서 기본값은 Generic으로 해 뒀어요.
